# .i3 Configuration

## Recommendations
1. This repository should be cloned to ~/.i3.
2. Add a symbolic link pointing to ~/.i3/dunstrc in ~/.config/dunst/
3. Disable Desktop -> Show Icons in gnome-tweaks (otherwise nautilus will launch a gnome desktop when it is launched)
